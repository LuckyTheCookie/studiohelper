# Studio Helper ✨

Studio Helper is a tool built for the **"Raconte-moi une histoire"** Discord community to help users install and troubleshoot [STUdio](https://github.com/marian-m12l/studio), a tool for managing story packs on Lunii devices.

Installing STUdio could be tricky for non-technical users, especially when it came to Java detection and configuration. Studio Helper was meant to simplify that whole process.

> ⚠️ This project was never fully completed and is no longer maintained.

## Features (planned/partial) 🛠️

- Automatic Java detection and troubleshooting
- STUdio installation guidance
- Auto-updater
- Problem solver for common installation issues

## Tech stack 💻

- **Python** (Flask for the web interface)
- **HTML / CSS / JavaScript** (frontend)
